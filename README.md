# Temperature Converter

A simple temperature converter project built in both **Ruby** and **Python**.

This project converts temperatures between **Celsius** and **Fahrenheit** based on the user's input.

I created this project as part of my programming practice to improve my understanding of user input, variables, conditionals, arithmetic operations, and basic program structure.

## Features

* Convert Fahrenheit to Celsius
* Convert Celsius to Fahrenheit
* Accept user input from the terminal
* Handle both uppercase and lowercase input
* Round converted temperatures for cleaner output

## Languages Used

* Ruby
* Python

Both versions perform the same basic task, allowing me to compare how similar logic is written in different programming languages.

## What I Practiced

While building this project, I practiced:

* Variables

* Data type conversion
* Conditional statements
* Arithmetic operations

## How It Works

The program first asks whether the starting temperature is in Fahrenheit or Celsius.

The user then enters a temperature.

The program checks the selected unit, performs the appropriate conversion, and displays the converted temperature.

## Example

